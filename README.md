# Shivam & Chanchal — Anniversary Website

A romantic, responsive anniversary website with an interactive eight-photo gallery, full-screen photo viewer, anniversary message, revealable wish, and optional looping soft-piano audio.

## Repository contents
- `index.html` — website
- `photos/` — eight wedding photographs
- `soft-piano-loop.wav` — original synthesized soft-piano-style loop

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.
4. Wait for GitHub Pages to finish deploying.

The website is intended to be public. Anyone with the URL can view the photographs. Music starts only after the visitor presses Play, in keeping with browser autoplay restrictions.
