# Shivam & Chanchal — Anniversary Website

A responsive wedding-anniversary experience with a photo gallery, full-screen photo viewer, personal wishes, and original synthesized ambient music (starts only after the visitor presses Play).

## Project files
- `index.html` — complete website, styling, interactions, and generated music.
- `photos/photo-01.webp` through `photos/photo-08.webp` — optimized wedding photographs.

## Publish with GitHub Pages
Use **Settings → Pages → Deploy from a branch → main → /(root)**.
