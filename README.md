# Shivam & Chanchal — Anniversary Website

A responsive anniversary website with an interactive wedding-photo gallery, full-screen photo viewer, anniversary message, and a revealable wish.

## Files
- `index.html` — website source
- `photos/` — reserved for the eight wedding photographs
- `soft-piano-loop.wav` — planned optional background music

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.
4. Wait for GitHub Pages to finish deploying.

The repository is public, so anyone with the website URL can view uploaded photographs. Music should start only after the visitor presses Play, in keeping with browser autoplay restrictions.
